# 🛡️ CompTIA Security+ Performance-Based Question Samples  

Practice your skills with this collection of sample Performance-Based Questions (PBQs) designed to help you prepare for the CompTIA Security+ (SY0-701) certification exam.

---

## 📚 About These PBQs  

Performance-Based Questions test your ability to apply knowledge in realistic scenarios.  
These samples cover key Security+ domains, including:

- 📝 **Security Controls**  
- 🎭 **Social Engineering**  
- 🔐 **Cryptographic Processes**  
- 📜 **Certificates**  
- 🗝️ **Access Control**  
- 🌐 **Remote Access**  
- ♻️ **Redundancy**  
- 🛑 **Vulnerabilities**

---

## 💻 How to Use Them  

These PBQs are provided as simple HTML files.  
Just open the landing page in your web browser and you’re ready to go:

1. Clone or download this repository.  
2. Open the `landingpage.html` file in your browser.  
3. Explore and practice each PBQ.
